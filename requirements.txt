# Not installable from this file, and both required:
#
#   Ollama           https://ollama.com    then:  ollama pull gemma4:12b
#   ESMFold weights  python scripts/fetch_esmfold.py    (~8.4 GB, resumable)
#
# Three notes that cost real time, recorded so they need not be rediscovered:
#
# 1. The original ESMFold docs recommend Python <= 3.9. On this setup Python
#    3.13 works: `transformers.EsmForProteinFolding` imports and
#    facebook/esm2_t12_35M_UR50D loads and scores correctly. The smoke test in
#    scripts/smoke_test.py is how that was established rather than assumed.
#
# 2. torch must come from the CPU index, or pip pulls a multi-GB CUDA build:
#      pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# 3. tmtools has no cp313 wheel and its sdist needs a C toolchain, so it is NOT
#    installed here. TM-score is computed by src/geometry.py's own
#    Zhang-Skolnick fragment-seeded implementation instead.
#    scripts/validate_tm_score.py measures the two against each other under an
#    interpreter that does have tmtools: agreement is 0.00015 for TM >= 0.74,
#    with a known underestimate of up to 0.06 below TM 0.5.
#    src/evaluator.py uses tmtools automatically if it is ever installed, and
#    pins tm_norm_chain2 either way.
