# web/ — the static replay demo

This directory is the whole of what gets deployed to Vercel. It is a plain
static site: no framework, no build step, no npm install. `vercel.json` points
`outputDirectory` here and `.vercelignore` keeps the Python project out of the
upload entirely.

## Why the real app is not deployed here

The Streamlit app in `app/streamlit_app.py` cannot run on Vercel, and no amount
of configuration changes that:

| Requirement | Vercel |
|---|---|
| Streamlit's long-lived server + WebSocket session | Functions are stateless and request-scoped |
| `torch` + `transformers` + `scipy` + `pandas` | Well past the 250 MB unzipped function limit — `torch` alone exceeds it |
| ESMFold checkpoint, 8.4 GB | Not in the repository (`data/models/` is gitignored) and far past any bundle limit |
| `gemma4:12b` served by local Ollama | No Ollama process exists in a serverless runtime |

The error Vercel reports first — `No python entrypoint found` — is only zero-config
detection tripping over `requirements.txt`. It is the first wall, not the only one.

So this page replays a recorded run instead, and says so on its face.

## Where the numbers come from

`data/demo.json` is generated by `scripts/build_web_data.py`, which distinguishes
two kinds of value and labels every one of them in the UI:

- **computed** — recomputed at build time by the project's own code
  (`src/geometry.py`, `src/pdb_io.py`, `src/cache/fold_cache.py`) from the
  committed ESMFold predictions in `data/cache/` scored against the real 1PGB
  crystal structure in `data/proteins/`. TM-score, contact recovery, sequence
  recovery, pLDDT and clash counts. None of these need torch, which is why they
  can be regenerated from a clean clone.
- **recorded** — transcribed from the verified run of 2026-07-30 written down in
  `DEMO.md`. The composite hidden score and Gemma's reasoning are here because
  the hidden score's ESM-2 term needs the model and `data/cache/esm_score/` is
  gitignored, and because `logs/` is gitignored so the run's own JSON was never
  committed.

A quantity that is neither computable nor recorded is emitted as `null` and the
page renders it as such — notably `substitutions_per_position` in the patched
policy, which is known to have increased but whose exact value lived only in
`logs/`.

The reference structure is gated behind a toggle. With the toggle off it is never
fetched, mirroring `build_viewer_models()` in `app/streamlit_app.py`.

## Regenerating

```bash
python scripts/build_web_data.py
```

Rewrites `web/data/demo.json` and `web/data/structures/*.pdb`. It refuses to run
if any structure resolves to the synthetic harness backend rather than a real
ESMFold prediction.

## Previewing locally

```bash
python3 -m http.server 8765 --directory web
```

Then open <http://localhost:8765>. `fetch()` needs a real HTTP origin, so opening
`index.html` from the filesystem will not work.

## Files

```
index.html          markup
styles.css          dark-first theme, light-mode counterpart, no webfonts
app.js              rendering + 3Dmol viewer; adds no numbers of its own
data/demo.json      generated bundle
data/structures/    corrupted / baseline / patched predictions + the reference
```

The only external dependency is 3Dmol.js from a CDN, loaded with a graceful
fallback message if it is unavailable.
