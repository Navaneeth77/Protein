Protein repair · self-revising search policy

ReFold

A protein-repair agent that rewrites its own search strategy when a hidden verifier disagrees with it.

ReFold takes a damaged protein sequence, repairs it, and is then told only one bit about how well it did. From that, a local LLM rewrites the agent's search policy — not its code, a constrained policy language — and the search runs again with different behaviour.

What this page is

This is a replay, not a live run. ESMFold is an 8.4 GB checkpoint and the policy reviser is a 12B model served by local Ollama — neither can run in a serverless function. Everything below comes from artefacts committed to the repository, and each number is labelled with how it got here:

  • computed recomputed in the browser build step by this project's own code (src/geometry.py, src/pdb_io.py) from the committed ESMFold predictions and the real 1PGB crystal structure. Reproduce with python scripts/build_web_data.py.
  • recorded transcribed from the verified run of 2026-07-30 documented in DEMO.md. The composite hidden score depends on an ESM-2 term whose cache is gitignored, so it cannot be recomputed here.

3 The loop, once

The agent repairs under a seed policy, the hidden verifier returns one scalar, and Gemma reads a grounded state graph and returns exactly one policy patch. Its only output channel is a fixed DSL — four scoring weights and three search parameters, schema-validated before the interpreter will touch it. It never emits code.

      5 Repair your own protein
      
    
      
      Paste a sequence. It gets folded, scored residue by residue, and repaired
      by the same policy the agent uses — then folded again so you can see what
      the repair did to the structure. Nucleotide input is translated first.
    
      

    
      
      
      
        
      
          
          
        
      
      
      
      
      
      
      

      
      
        
        
        
        
        
      
      

      
      
      
        
    
        

    
        
      
        
        What this can and cannot tell you. There is no reference
        structure for a protein you supply, so nothing here is scored against
        ground truth — that is the whole point of the hidden verifier in
        section 3, and it does not exist for your input. What
        you get is honest and limited: where ESM-2 finds the chain implausible,
        what substitutions it prefers there, how sequence likelihood and the
        model's own confidence move, and how far the predicted structure shifts.
        A repair that raises all three is a good hypothesis, not a verified fix.

        6 Running it for real
        
    
        
      The live pipeline runs locally. It needs the ESMFold checkpoint and Ollama;
      the fold cache ships with the repository so the demo does not re-fold.
    
        
    
        git clone https://github.com/Navaneeth77/Protein.git
cd Protein
pip install -r requirements.txt
pip install torch --index-url https://download.pytorch.org/whl/cpu

python scripts/fetch_esmfold.py     # ~8.4 GB, resumable
ollama pull gemma4:12b

./run_mvp.sh                        # macOS / Linux
.\run_mvp.ps1                       # Windows
        
    
        
      Then open http://localhost:8501 and press Run ReFold.
